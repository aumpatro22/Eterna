## 2025-02-08 - [Incomplete Bleach Migration]
**Vulnerability:** The application was using the deprecated `bleach` library for HTML sanitization in models (`communities/models.py` and `memorials/models.py`), but `bleach` was actually uninstalled in `requirements.txt` and replaced by `nh3`, causing internal server errors on model saving. Furthermore, `bleach` often leaves text contents of stripped malicious tags, while `nh3` properly cleans it.
**Learning:** `bleach` was partially replaced by `nh3` in the `tales/models.py` and `users/models.py` previously, but the migration wasn't finished in other models, which actually broke creation of new objects and test suites. `nh3` behaves differently by entirely stripping tags and their internal text (like `<script>alert(1)</script>`), so tests must be updated to expect the full text to be removed, not just the tags.
**Prevention:** When migrating third party libraries, ensure all usages in all files are properly searched and replaced, and always run the test suite to catch runtime `ModuleNotFoundError` errors caused by removing a dependency.
